# 📘 Learning Android -- Proyecto en React Native

Aplicación móvil desarrollada con **React Native**, **Expo** y
**TypeScript**, que incluye pantallas de autenticación, registro,
navegación, perfil e integración con **Supabase**.

------------------------------------------------------------------------

## 🚀 Tecnologías utilizadas

-   React Native
-   Expo
-   TypeScript
-   Supabase
-   Node.js
-   React Navigation

------------------------------------------------------------------------

## 📦 Instalación

Clona el repositorio:

``` bash
git clone https://github.com/usuario/learning-android.git
```

Instala las dependencias:

``` bash
npm install
```

------------------------------------------------------------------------

## ▶️ Iniciar el proyecto

El proyecto se inicia con el siguiente comando:

``` bash
npx expo start --tunnel
```

------------------------------------------------------------------------

## 📱 Funcionalidades principales

-   Pantalla Splash
-   Login
-   Registro
-   Home
-   Menú principal
-   Perfil
-   Navegación con React Navigation
-   Conexión a Supabase
